# 📘 Tutorial: intro-to-geospatial
Deze tutorial was ontwikkeld als onderdeel van de epi-netwerkdag 2026, voor en door GGD epidemiologen. 
Datum: 03/11/2026
Plaats: RIVM

## 🦠 Practicum: Mazelenuitbraak in de regio
In deze tutorial ga je als epidemioloog aan de slag met een fictieve mazelenuitbraak:
Tijdens de zomervakantie zijn enkele ongevaccineerde kinderen teruggekeerd van vakantie, waar zij mazelen hebben opgelopen. Na thuiskomst hebben ze met vriendjes en vriendinnetjes in de buurt gespeeld en bij familie gelogeerd. De uitbraak verspreidt zich langzaam door de bovenregio.

Jij bent als epidemioloog gevraagd om:
1. De mazelengevallen in de hele bovenregio te visualiseren.
2. Het risico op verspreiding naar andere regio's te beoordelen.
3. Te onderzoeken welke scholen extra aandacht nodig hebben voor vaccinatie, nu het schooljaar bijna begint.

## 🎯 Doel
Na deze tutorial kun je:
- Verschillende types geo-data laden in R
- Kaartjes maken waarin je verschillende types geo-data combineert
- Adressen aan coördinaten koppelen
- Simpele bewerkingen en berekeningen met geo-data
- Heb je wat inspiratie voor wat misschien verder mogelijk is in de toekomst

## 📋 Benodigdheden
- Je hebt R en Rstudio geïnstalleerd op jouw laptop
- De benodigde R packages vind je in `packages.R`

## 🚀 Aan de slag

Je kunt de tutorial op twee manieren op je computer zetten.

### Optie 1: Downloaden (makkelijkst)
1. Klik bovenaan deze GitHub-pagina op de groene knop **Code**.
2. Kies **Download ZIP**.
3. Pak het gedownloade ZIP-bestand uit op je computer.
4. Open de map en dubbelklik op het `.Rproj`-bestand om het project in RStudio te openen.

### Optie 2: Clonen met RStudio
Handig als je later eenvoudig de nieuwste versie wilt ophalen.

1. Klik op de groene knop **Code** op deze GitHub-pagina.
2. Kopieer de URL onder **HTTPS**.
3. Open RStudio en ga naar **File → New Project → Version Control → Git**.
4. Plak de URL bij **Repository URL**.
5. Kies waar je het project wilt opslaan en klik op **Create Project**.

Je kunt nu met de tutorial aan de slag!
